# 需求:按类型分组(视图切换)

- 状态:待确认
- 日期:2026-08-14

## 背景

当前面板**按域名分组**:同一站点的标签页聚在一起,单 tab 域名自动折叠(`panel/panel.js` 的 `buildGroups` + `isGroupCollapsed`)。

痛点:当打开的域名很多且大多只开了一个页面时,即使单 tab 分组已折叠,每一行折叠态的分组头(箭头 + 字母图标 + 域名 + 数量 + 全选 + hover 操作)仍占一整行。开 30 个不同网站 ≈ 30 行分组头,界面依然杂乱。

目标:新增**按类型分组**视图,把零散的单页站点收拢进少数几个类型分组,减少视觉噪音;原按域名视图保留为默认,两者一键切换。

## 用户故事

- 作为浏览器重度用户,我希望看到"技术 / 新闻 / 社交…"这样的分类视图,把零散站点收拢,以便更快定位和批量管理。
- 我希望在"按域名"与"按类型"之间一键切换,且默认保持按域名。
- 我希望冷门站点能被我自己归入某个分类,而不是永远堆在"其他"里。

## 功能需求

### FR-1 视图切换
- 面板顶部提供切换控件:「按域名 | 按类型」。
- 默认按域名,与现状完全一致。
- 切换后立即重渲染;搜索关键词、勾选状态在切换时保留。
- 用户的选择跨会话持久化(`chrome.storage.local`)。

### FR-2 按类型分组
- 每个可管理 tab 经分类器得到分类,按分类分组。
- 组内 tab 排序:先按域名、域名内按 tab index,让同域名 tab 相邻。
- 单 tab 分类组沿用现有智能折叠逻辑(自动折叠,用户手动展开后跨会话记住)。
- 分类展示名 + 组内 tab 仍逐行显示域名/URL。

### FR-3 分类规则(内置)
- 内置「域名 → 分类」规则表,覆盖约 10 个分类:
  技术/开发、新闻/资讯、社交/社区、视频/影音、搜索、办公/效率、AI 工具、购物、金融/理财、其他(兜底)。
- 未匹配任何规则的域名一律归入「其他」。
- 子域名精度:具体规则优先于父级规则(如 `mail.google.com → 办公` 优先于 `google.com → 搜索`)。
- 分类器为纯本地确定性计算,无网络请求。

### FR-4 自定义规则
- 用户可新增/删除自定义规则:域名 + 分类。
- 自定义规则存 `chrome.storage.local`,叠加在内置表之上,优先级高于内置规则。
- 添加/删除后立即生效并重渲染。

## 非功能约束

- 全本地处理,无网络请求,扩展权限不变,无隐私数据外发。
- 分类计算在本地即时完成,大 tab 数下不引入可感知开销。
- 折叠/展开状态、视图选择、自定义规则均跨会话持久化。
- 现有全部能力(搜索、勾选、批量关闭/挂起、分组级操作、最近关闭)在两种视图下均可正常使用。

## 验收标准

- AC-1 默认打开面板为「按域名」视图,展示与现状一致。
- AC-2 切到「按类型」,所有可管理 tab 正确归入分类;未匹配域名落入「其他」。
- AC-3 单 tab 分类组自动折叠;手动展开后跨会话记住。
- AC-4 搜索状态下切换视图,勾选与批量操作只作用于可见 tab。
- AC-5 添加自定义规则后,对应域名立即归入指定分类;删除后恢复内置规则或「其他」。
- AC-6 扩展权限未变,无新增网络请求。
- AC-7 视图选择在面板重开/重载后保持。

## 非目标(本期不做)

- 不引入 AI/在线分类服务。
- 不做「类型 → 域名」两级嵌套分组(保持单层,避免 UI 复杂度)。
- 不做规则导入/导出。
